# Privacy Policy

Effective date: 2026-10-18

GitHub PR Helper is a skill-only plugin maintained by `man178197`. This policy
describes the plugin package's own data practices.

## Data collection

The plugin has no server, analytics, telemetry, advertising, accounts, or
persistent data store. The plugin package does not independently collect,
retain, sell, or share personal information.

## Data processing

The plugin operates inside the host application where it is installed. Pull
request URLs, repository content, prompts, and generated review results are
processed by that host and by services the host connects to. The Codex or
ChatGPT host processes the conversation under its own terms and privacy policy;
GitHub processes repository and pull request requests under GitHub's terms and
privacy statement.

Do not include credentials, personal data, or other secrets in prompts or issue
reports unless you have independently confirmed that the destination and host
are appropriate.

## Data retention and deletion

The plugin does not retain data. Retention of conversation history, logs, and
GitHub activity is controlled by the host, GitHub, and the user's settings.

## Third-party links

The plugin may direct the host to public GitHub URLs provided by the user.
Opening or querying those URLs is subject to GitHub's policies.

## Changes

Material changes to these practices will be recorded in this file and the
repository's version history.
