# Security Policy

## Supported versions

Security fixes are applied to the latest published version.

## Report a vulnerability

Do not disclose vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting for this repository:

https://github.com/man178197/github-pr-helper-plugin/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include live credentials or unrelated private data. If
private reporting is unavailable, open a public issue that contains no
sensitive details and ask the maintainer for a private reporting channel.

## Scope

Relevant reports include unsafe instructions in the plugin package, unsupported
or unsafe command execution, credential exposure, and validation workflow
problems.
