# Support

Use GitHub Issues for bug reports, installation problems, and feature requests:

https://github.com/man178197/github-pr-helper-plugin/issues

When reporting a problem, include:

- The plugin version;
- The Codex version and operating system;
- The prompt used (with private data removed);
- Whether the PR base/head was identified correctly;
- A short description of the expected and actual result.

Do not post access tokens, passwords, private repository contents, personal data,
or security vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md)
for security reports.
